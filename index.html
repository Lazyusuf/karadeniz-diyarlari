Quick Start

To ensure quests work properly, you need to download the cm_messages.xml file and place it in your game data folder.

1

Download the File

Download the required configuration file from Google Drive.

⬇️ Download
2

Copy the File

Place the downloaded file in your game's data folder:

...\Steam\steamapps\common\Life is Feudal Your Own\data\
3

Restart the Game

Please make sure the game is closed before copying the file. Then launch the game.
