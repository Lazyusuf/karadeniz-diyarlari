📁art/
📁data/
📁gui/
📁mod/
📁scripts/
📄license.txt
💡

Note: Copy ALL folders and files listed above to your game directory.

🎯

Installation Steps

1

Download Jorvik MOD

Get the complete MOD package from our repository

⬇️ Download MOD
2

Close Game

Ensure Life is Feudal is completely closed before installing

3

Copy All Files

Copy ALL folders and license.txt to:

...\Steam\steamapps\common\Life is Feudal Your Own\
4

Overwrite if Asked

Click "Yes to All" when prompted to replace existing files

5

Launch & Enjoy

Start the game and experience enhanced Black Sea Realms

❓

Quests Not Working?

Make sure cm_messages.xml is in the correct location:

...\Life is Feudal Your Own\data\cm_messages.xml
🎮

Game Crashes?

Verify game files through Steam:
Right Click LiF → Properties → Local Files → Verify Integrity

🔄

MOD Conflicts?

Remove any other MODs before installing Jorvik. Clean installation recommended.
